PARADIS TRIM 1.0.2
Part of Paradis EZ Utilities - simple tools for simple jobs.

A simple way to cut audio and video down to the part you actually want.

HOW TO USE
  1. Double-click "Paradis Trim.exe".
  2. Drop an audio or video file on the window (or click Choose File).
  3. Drag the blue handles so the highlighted part is what you want to keep.
  4. Click "Save Trimmed Copy".

The trimmed copy is saved next to the original, e.g. Song.mp3 -> Song_trimmed.mp3.
To save somewhere else, click "Change" under SAVE TO. Your original file is never changed.

Settings (top right) lets you change the "_trimmed" ending and choose whether
File Explorer opens after each save.

Works with MP4, MOV, M4V, MP3, WAV and M4A files. Windows 10 or 11 (64-bit).
Nothing else needs to be installed.

Keys: Space = play/pause, Left/Right = move 1 second (Shift: 0.1 s),
      [ = start here, ] = end here.

If Windows says "Windows protected your PC", click "More info" and then "Run anyway".
(The app is not code-signed yet.)

PRIVACY
Your media stays on your computer. Paradis Trim processes files locally and does
not upload them. No account, no telemetry, no internet connection needed.

Keep the "ffmpeg" folder next to Paradis Trim.exe - Paradis Trim needs it.
